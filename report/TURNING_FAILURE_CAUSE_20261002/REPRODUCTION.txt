Run scripts from the repository MATLAB environment, using the original paths in their headers.
1. analyzeFrame.m reconstructs all collision rows and asserts equality with the saved
   problem before varying normals, buffer, or numerical correction bounds. Twelve
   conic ablations and twelve finite braking probes are exported. No online source
   file is changed.
2. compareSecondary.m needs an external probeSecondary.m: extract the original
   controller/solvePredictiveControl.m starting at the localSecondary function,
   retaining all following local functions, and rename only that first function
   from localSecondary to probeSecondary. Put the helper in the diagnostic cache,
   not the repository. The script reruns three variants through the unchanged CLF
   stage on the modified safety rows.
3. exportComparison.m verifies those three complete input sequences using tight
   tolerance ODE45 and outputs 11 samples per 50-ms hold, including duplicate
   boundary nodes. It compares fixed-normal and true rectangle separation.
4. renderComparison.py [DATA_DIRECTORY] [OUTPUT_DIRECTORY] creates figures outside
   the repository. The first two panels use exactly the same vehicle poses. The
   third panel reproduces the prior one-row upper bound, not that candidate's
   geometry or a full feasible solution.

counterfactual-*.csv columns: absoluteTime, ego x,y,yaw,vx,vy,yawRate,
target x,y,yaw, Euclidean rectangle distance (zero at overlap).
Comparison inputs are open-loop counterfactuals from the recorded t=0.85 s state;
these are not new closed-loop campaign results, global feasibility certificates,
or claims of continuous safety or endpoint membership.
The angle experiments rotate every collision normal whose absolute timestamp is
in [1.4,1.9] s; dynamics, original flow anchor, prefix/tail structure and endpoint
cone are preserved. Rotation is a diagnostic perturbation, not a proposed mode
bank or an implemented controller fix.
